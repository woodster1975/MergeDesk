# MergeDesk captioned walkthrough

MP4 using app screenshots, instructional captions and an original cheerful instrumental backing track. Pause to read or inspect a screen. No live emails were sent to make this video.

## 00:00 — Welcome to MergeDesk

Create personal messages from your recipient list. This captioned walkthrough shows the workflow; pause whenever you need more time.

## 00:10 — 1. Load your recipients

Click Load CSV / Excel and choose a CSV or .xlsx workbook. For Excel, select the worksheet number, then Reload.

## 00:23 — 2. Map your merge fields

Each merge field gets its value from a source column. Edit names or add mappings. Use fields from your own data; no AccountNo column is required.

## 00:38 — Choose which recipients to include

Ticks control the batch. Search only changes visible rows: hidden ticked recipients still count. Exclude all, search, then Include shown to choose a group.

## 00:53 — 3. Choose recipients and subject

To can use {{Email}}. CC and BCC are optional. Place the subject cursor, choose a field, then click Insert merge field in subject.

## 01:08 — 4. Write and format your message

Write in the visual editor. Select text to change font, size, colour, bold, italic or underline. Alignment and list buttons format paragraphs.

## 01:23 — 5. Insert fields and images

The body has its own field picker. Insert image embeds a PNG, JPEG or GIF at the cursor; each picture may be up to 2 MiB.

## 01:38 — 6. Keep the plain-text version current

Click Use email text for plain-text version after editing. You can adjust that version separately. HTML is generated automatically; Advanced HTML source is optional.

## 01:53 — 7. Add optional attachments

Global files go to every recipient. Per-recipient paths accept one absolute path per line, using mapped tokens such as {{Reference}} when needed.

## 02:08 — 8. Validate and preview

Validate all checks addresses, fields, duplicates and attachments. Fix every issue. Select a source row and Refresh preview to inspect the merged email.

## 02:23 — 9. Connect classic Outlook

Choose classic Outlook, connect, then select the intended account. Your mailbox must already be configured in the classic Outlook profile on this computer.

## 02:37 — 10. Connect a Microsoft mailbox

For new Outlook with Microsoft 365 or Outlook.com, enter your app client ID and tenant, then sign in. README explains registration. Reconnect after enabling direct sending.

## 02:54 — Send one test email first

Choose a source row and enter your own test address. Confirm one real test email with CC and BCC cleared. Its subject starts with [TEST].

## 03:09 — 11. Test locally or create drafts

Export dry run writes local files without sending. Create Outlook drafts puts messages in Drafts after confirmation. Review drafts in Outlook before a larger batch.

## 03:25 — 12. Send only when ready

Set the delay between sends, then Send emails. Check the account and count in the final confirmation. Cancel stops future work; submitted messages cannot be recalled.

## 03:42 — 13. Read results before retrying

History shows each row’s outcome. Direct-send retries skip matching submitted messages. Uncertain submissions need review in Outlook; manually sent drafts are outside this protection.

## 03:59 — Autosave and recovery

Changes autosave after idle editing. At startup, Restore autosave brings back your work; Start fresh dismisses it. Outlook stays disconnected and no sends restart.

## 04:13 — Help is always close by

Press F1 or click Help. Search the guide for a topic, hover over an option for a tooltip, or replay this video. Save your project before closing.
